## Purpose
A single-page online library catalogue where users can browse, search, filter, add and borrow books.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (no frameworks or libraries)

## Main Features
1. **Display books** – cards are built from a JavaScript array.
2. **Search and filter** – search by title while typing, filter by category; both work together.
3. **Add Book** – validated form; new books appear immediately without reloading.
4. **Borrow** – reduces copies by 1; shows "Out of stock" and disables the button at 0.
5. Responsive layout: 3 cards per row on desktop, 2 on tablet, 1 below 600px.
